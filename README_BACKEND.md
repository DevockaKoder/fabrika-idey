# 🚀 Как запустить бэкенд для GigaChat (для GitHub Pages и Vercel)

Так как Сбербанк блокирует прямые браузерные запросы (CORS и сертификаты Минцифры), для работы GigaChat нужен легковесный сервер-посредник (бэкенд). 

В этот проект уже включены все готовые решения. Выберите самый удобный для вас вариант:

---

## 🥇 Вариант 1 (Самый простой): Деплой на Vercel (1 минута, 100% бесплатно)
Вместо связки «GitHub Pages + отдельный бэкенд» вы можете развернуть всё приложение целиком на **Vercel**:
1. Зайдите на [vercel.com](https://vercel.com) и войдите через свой GitHub-аккаунт.
2. Нажмите **«Add New...» ➔ «Project»**.
3. Выберите репозиторий с этим приложением и нажмите **«Deploy»**.
4. **Готово!** Vercel автоматически развернёт и фронтенд, и наш серверный маршрут `/api/gigachat` (файл `api/gigachat.ts`). Вы получите красивую ссылку вида `https://prompt-trainer.vercel.app`, которая будет работать у всего класса без CORS и настроек!

---

## 🥈 Вариант 2: Оставить сайт на GitHub Pages + Бесплатный бэкенд на Render.com
Если сайт уже на GitHub Pages и вы хотите оставить его там:
1. Зайдите на [render.com](https://render.com) (бесплатная регистрация).
2. Нажмите **«New +» ➔ «Web Service»** и выберите ваш GitHub-репозиторий.
3. Укажите:
   - **Build Command**: `npm run build`
   - **Start Command**: `npm start`
4. Нажмите **«Create Web Service»**.
5. Скопируйте полученный адрес сервиса (например, `https://my-gigachat-proxy.onrender.com`).
6. Откройте ваш сайт на GitHub Pages, нажмите вверху **«🔑 Ключ API»** и в поле **«URL бэкенд-сервера»** вставьте эту ссылку. Теперь GitHub Pages будет обращаться к вашему бэкенду!

---

## 🥉 Вариант 3: Локальный запуск на компьютере учителя (в кабинете информатики)
Если все компьютеры учеников находятся в одной локальной сети или Wi-Fi школы:
1. На компьютере учителя скачайте проект и запустите:
   ```bash
   node backend-server.js
   ```
2. Узнайте локальный IP-адрес компьютера учителя (например, `http://192.168.1.50:3001`).
3. В файле `src/config/apiKeyConfig.ts` укажите:
   ```ts
   export const DEFAULT_BACKEND_URL = 'http://192.168.1.50:3001';
   ```
   Или введите этот адрес в окне «Ключ API» на компьютерах учеников.
