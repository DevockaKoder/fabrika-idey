📖 Инструкция: Как выложить на GitHub Pages за 2 минуты

1. Создайте репозиторий на GitHub

Зайдите на github.com/new, введите имя (например: fabrika-idey), выберите Public и нажмите «Create repository».

2. Загрузите файл index.html

В репозитории нажмите Add file ➔ Upload files. Перетащите сохранённый файл index.html и нажмите Commit changes.

3. Включите Pages в настройках

Перейдите в Settings ➔ Pages ➔ Branch, выберите ветку main и папку / (root), затем нажмите Save.

4. Готово!

Через 1 минуту сайт будет доступен по ссылке вида: https://<username>.github.io/fabrika-idey/
