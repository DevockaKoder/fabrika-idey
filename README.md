# 💡 ИИ-сервис «Фабрика идей»

**КГЭУ, кафедра ИТИС.** Сервис для продумывания идей школьных проектов: ученик выбирает
ИИ-помощника, обсуждает с ним свою идею, а затем собирает лучшие фрагменты в готовый отчёт.

Собрат тренажёра «Промпт-инженер» ([profproba89](https://github.com/DevockaKoder/profproba89)):
та же архитектура, но назначение другое — **не тренажёр промптинга, а сервис продумывания идей**.
Системные промпты помощников зашиты «под капотом» (файл `src/data/scenarios.ts`) и не редактируются
в интерфейсе.

## 🤖 ИИ-помощники (5 ролей)

| Помощник | Чем помогает | Главное правило (под капотом) |
|---|---|---|
| 🎓 **Научный руководитель** (Вера Александровна) | Превращает смутную идею в тему: актуальность → цель → задачи | Не делает работу за ученика |
| 💡 **Генератор идей «Идея-Бум»** | Мозговой штурм: ровно 3 идеи с плюсами/минусами и сложностью | Всегда три варианта на выбор |
| ⚖️ **Строгий рецензент** (профессор Рецензов) | Честно ищет слабые места: слабое место → почему → как исправить | Критикует идею, а не человека |
| 🎤 **Тренер защиты проекта** (коуч Тимур) | Структура выступления, слайды, репетиция каверзных вопросов | Не отвечает за ученика на защите |
| 📚 **Библиотекарь-исследователь** (Мира Эльдаровна) | План исследования, типы источников, проверка достоверности | Не выдумывает точные ссылки |

При смене помощника диалог очищается — каждый помощник ведёт свою линию обсуждения.

## 📤 Выгрузка идеи

Помимо кнопки «Скачать диалог» (стенограмма .txt) есть панель **«Выгрузка идеи»**: 5 полей,
в которые ученик вставляет скопированные из диалогов фрагменты. Кнопка «Сформировать и скачать
отчёт» собирает их в текстовый отчёт вида:

```
Аффилиация: КГЭУ, кафедра ИТИС
Ссылка на сайт: <адрес сервиса>
Ученик: ...
Дата: ...

Идея 1: ...
Идея 2: ...
```

Пустые поля пропускаются, идеи нумеруются по порядку, черновики сохраняются в браузере.

## 🚀 Запуск

**Полная версия (React + сервер):**
```bash
npm install
npm run dev        # http://localhost:3000 — фронтенд + встроенный прокси ГигаЧата
```

**Автономная версия для GitHub Pages (один файл):**
откройте `public/standalone.html` — работает полностью в браузере. Без ключа включается
демо-эмулятор; ключ вводится в панели «🔑 Ключ API / Демо».

**Лёгкий бэкенд-прокси (для GitHub Pages / локальной сети):**
```bash
node backend-server.js   # http://localhost:3001
```

## 🔑 Ключ GigaChat

Ключ вшит в `src/config/apiKeyConfig.ts` (константа `DEFAULT_API_KEY`) — приложение
сразу работает на всех компьютерах без настройки. Полный цикл (OAuth-обмен → chat/completions)
выполняет серверный прокси: `api/gigachat.ts` (Vercel), `server.ts` (dev/prod Express),
`backend-server.js` (автономный, Node 18+). Подробнее: [README_BACKEND.md](README_BACKEND.md).

Аффилиация и ссылка на сайт для отчётов настраиваются в `src/config/serviceInfo.ts`
(константы `AFFILIATION` и `SERVICE_URL`; если `SERVICE_URL` пуст — берётся адрес текущей страницы).
